# Aplikacja Webowa EBoard przepisana do frameworku Django z frameworku Flask

- Dodałem tagi dla postów oraz zmieniłem wyszukiwanie aby umożliwić wyszukiwanie postów po opisie i tagach.

# Zakres korzystania z pomocy samouczków i AI:

# Uruchamianie
- 1. python manage.py makemigrations
- 2. python manage.py migrate
- 3. python manage.py runserver
